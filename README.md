# design-portfolio

Shaifur Rahaman — UI/UX & product designer. Live at https://shifat71.github.io/design-portfolio/

- `index.html` — the portfolio: PinkTrack and EcoSync case studies, style studies, contact.
- `screens/` — app screenshots (EcoSync images resized to WebP with metadata stripped).
- `concepts/` — twelve self-contained style-study pages (glassmorphism, neumorphism, neo-brutalism, bento, claymorphism, aurora, Swiss, skeuomorphic, Y2K, editorial, terminal, spatial) and their thumbnails.

Static HTML and CSS, no build step. The glassmorphism refraction and neo-brutalist button are adapted from 21st.dev components by educalvolpz ("Glass Card") and radiumcoders ("Brutal Button").
